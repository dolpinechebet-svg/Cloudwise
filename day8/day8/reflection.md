# Reflection

## The most difficult concept

The most difficult concept in this course was asynchronous JavaScript, especially using `fetch` with `async` and `await`. At first I did not understand why my page showed nothing while the data was still loading, or why errors did not appear. I overcame it by working in small steps. I added a status message for loading, success and error, used `try`, `catch` and `finally`, and tested the error path by breaking the URL on purpose. Seeing the messages change on the page helped me understand the order in which things happen.

 What I would improve

Feedback on my first project showed me that small details matter. A wrong ID in my JavaScript and a missing `#` in my CSS stopped features from working, even though the idea was right. For my capstone, I would check every name and number twice before submitting, and I would test the API client more carefully. I would also explain more clearly how the cache and the read replica stay up to date, because that is where the design has the most trade-offs.

## What I will learn next

Next, I want to learn how to build a real backend with Node.js and a SQL database, so that my client can talk to my own API instead of a practice one. I also want to learn more about authentication and about testing, so I can find bugs before other people do.
